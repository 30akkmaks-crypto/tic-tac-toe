# Tic-Tac-Toe 

Классическая игра «Крестики-нолики» (Tic-Tac-Toe) на 7 языках программирования. Каждая версия поддерживает:

- **Два режима**: два игрока (локально) или против компьютера (AI)
- **Умный AI** с использованием алгоритма минимакс (Minimax) – компьютер играет оптимально
- **Счёт побед и ничьих** (по сессиям)
- **Подсветка выигрышной линии** (три в ряд)
- **Кнопка сброса / реванша**
- **Индикация текущего игрока / победителя**

## Реализации

| Язык | Технология | Особенности |
|------|------------|-------------|
| Python | Tkinter / Pygame | GUI, AI minimax |
| Go | Ebitengine | 2D графика, AI |
| Rust | ggez | Производительный AI |
| C# | Windows Forms | Классический интерфейс |
| JavaScript | HTML5 Canvas | Браузерная версия |
| TypeScript | Canvas + классы | Типизированная версия |
| Java | Swing | Кроссплатформенный GUI |
